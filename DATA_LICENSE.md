# Dataset provenance

Brazilian E-Commerce Public Dataset by Olist, https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce (CC BY-NC-SA 4.0, https://creativecommons.org/licenses/by-nc-sa/4.0/).

The original data covers anonymized marketplace orders from 2016–2018. Use for noncommercial portfolio analysis with attribution; redistributed adaptations must retain applicable share-alike terms. Download the nine original CSV files from Kaggle into `data/`. Do not commit credentials, generated databases or raw archives. Full-data metrics must be regenerated from the actual CSV files, not synthetic fixtures.
